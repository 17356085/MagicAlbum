## 实现范围

- 上传先登记意图，再写 provider，最后提交 READY、任务和请求 Outbox；原 URL 保持兼容。实际字节、格式、尺寸、像素和摘要均有校验。
- Java 在短事务中持有领取、续租、候选与结果的权威状态；Go 不直接访问数据库或 S3。回传按输入摘要、版本和当前租约验证，结果对象使用资源/版本/预设/处理器/摘要路径。
- 发布和延迟重试使用持久化、mandatory 与确认；终态接受后才 ACK。过期租约和已发布但未执行的请求可恢复，用户重试产生新版本。
- 派生清理保护当前候选和已接受输出，保留未知任务及原图；本地扫描能越过首批条目。对象网络调用与发布/通知调度隔离。
- 图片状态按账号缓存最近 20 条并向后端核实；支持原图、预览、停止与重试。适配手机纵横屏，单一滚动区域，不自动改写正文。
- 通知变化与数据同事务，按账号串行分配游标；SSE 支持断线重放、JWT 到期、心跳和连接数量上限。前端连接、迟到回调及轮询随身份/页面生命周期结束。
- 可选 Compose 扩展、独立服务令牌、健康检查、资源限制、回退和排障入口已提供，见[运行手册](m3-operations.md)。
