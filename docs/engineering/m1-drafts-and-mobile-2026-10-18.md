## 问题与处理

| 问题 | 处理和边界 |
| --- | --- |
| 输入后未满 800ms 即离页，最后一段草稿可能没有保存 | 自动保存同步捕获账号键和序列化内容快照，路由卸载、账号切换、`pagehide` 时写入原键；正常输入仍保留 800ms 防抖 |
| 账号切换时，旧表单值或旧定时器可能进入新账号槽位 | 停止旧 watcher 后 flush 原快照，再恢复新账号；定时回调继续校验当前键。身份未确定时禁写；访客和旧无归属草稿规则不变 |
| 清除或发布后，离页 flush 可能复活旧草稿 | 清除同时取消 pending；发布成功先停止自动保存并清除，再重置表单。未修改的空表单和恢复动作不触发新草稿 |
| 浏览器拒绝写入时仍提示手动保存成功 | 保存返回实际成功状态，失败显示提示。自动离页保存仍是尽力保存，不能保证浏览器崩溃、进程被杀或存储禁用时持久化 |
| 手机搜索按 Esc 后，焦点留在隐藏的输入框 | 面板内输入框或按钮都支持 Esc 关闭并回到搜索入口；外部点击不抢焦点，桌面搜索不受此关闭逻辑影响 |
| 320px 登录顶栏中登出入口超出屏幕 | 调整小屏留白、组件间距及登出按钮宽度；保留 36px 按钮和桌面布局。导航文字也缩减内边距，四个入口均可显示 |

没有改动 API、数据库、权限或后端业务语义。详情评论定位、更多页面与缩放组合仍需后续覆盖，不将本批描述成全站所有断点已经验收。
