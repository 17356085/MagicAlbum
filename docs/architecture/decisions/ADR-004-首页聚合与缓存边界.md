# ADR-004 · 首页聚合与缓存边界

首页初次加载需要帖子、分区、用户资料、关注动态和未读通知。新增网关 `GET /api/v1/home/overview` 并发请求各数据 owner，保留原有分页、搜索、通知流和更新入口。

公开帖子与分区可在网关进程缓存两秒。个性化资料、关注动态和未读通知只有在请求带用户凭证时才调用，组合响应使用 `Cache-Control: no-store`。子请求有独立超时，超时资源返回空值及 `unavailable` 字段，页面可继续独立请求该资源。核心拒绝用户凭证时，组合入口返回相应认证状态。

隔离试点同时开启网关与前端开关 `BLUEALBUM_HOME_BFF_ENABLED=true`。前端在未过滤的首页首屏和侧栏复用聚合结果。按条件查询与后续分页继续沿用单项 API。回退时关闭开关并重建前端和网关配置。
